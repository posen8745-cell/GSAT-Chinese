# GSAT-Chinese｜學測國文練習室

靜態 GitHub Pages 專案，與 GSAT-Math 的介面規格接近，但**國綜／國寫題型與測驗時間按國文科調整**。

## 上傳

把本資料夾內的 `index.html` **與 `questions.json` 一起**上傳到 GitHub Repository `posen8745-cell/GSAT-Chinese` 的根目錄。可一併上傳本 `README.md`。在 Settings → Pages 啟用 `main` + `/(root)`，網址為 `https://posen8745-cell.github.io/GSAT-Chinese/`。

> 如果只上傳 `index.html`，網站仍可載入原本舊版的 `questions.json`，但新增加的題目不會出現，所以兩個檔案都要更新。

## 網站功能

- 官方試卷索引：108–115 學年度大考中心國文（選擇題／國綜）及國寫官方頁面。108–115 每學年度均提供已核對的國綜／國文選擇題、官方答案及國寫原卷直接 PDF 連結。**官方原題全文不在此 JSON 題庫內**。
- 國綜分類逐題練習：**28 題**（原始 5 題與新增自編 23 題），單選／多選、全文段落、答案解析，單題完整在頁面顯示。
- 可選題型、題數、隨機抽題、90 分鐘限時練習；儲存未完成進度。題型練習用整題正確率，不等同官方配分或級分。
- 錯題再測、訂正筆記、成績統計、匯出／匯入 JSON。
- 自編國寫練習與草稿儲存，須人工評閱。

## 擴充題庫

`questions.json` 是 UTF-8 JSON 陣列，每題欄位：

```json
{
  "id":"q101",
  "type":"白話閱讀",
  "multi":false,
  "pass":"自編閱讀段落",
  "stem":"題幹",
  "opts":["選項一","選項二","選項三","選項四","選項五"],
  "ans":"2",
  "exp":"解析",
  "source":"自編練習"
}
```

多選時 `multi:true`，`ans` 使用排序好的選項編號，例如 `"125"`。題目若取自正式試卷，應另行核對來源、著作權與完整題組資訊；**不能把自編題寫成官方原題**。

## 資料隱私

答案、筆記和草稿只存在瀏覽器的 localStorage，不會上傳到伺服器。更換裝置或清除瀏覽器資料前請匯出紀錄。
